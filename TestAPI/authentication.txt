1. Register User (No Authentication)
Method: POST

URL: http://localhost:3000/api/register

Body (JSON):

{"name":"Abhinesha1",
  "username": "Abhinesh1a",
  "email": "Abhinesha1@example.com",
  "password": "adminpassword123",
  "phone": "0987654321"
}



2. Login User (No Authentication)
Method: POST

URL: http://localhost:3000/api/login

Body (JSON):

{
  "email": "Abhinesha1@example.com",
  "password": "adminpassword123"
}

Response: You'll get a token like:

{
  "token": "your_jwt_token_here"
}

3. Forget Password (No Authentication)
Method: POST

URL: http://localhost:3000/api/forgetPassword

Body (JSON):

{
  "email": "john.doe@example.com"
}

4. Protected Routes (Require Token)
For these routes, add a Bearer token in the Authorization tab of Postman:

Authorization: Type: Bearer Token → Paste the token from login response.

Logout
Method: POST

URL: http://localhost:3000/api/logout

Delete User
Method: POST

URL: http://localhost:3000/api/delete

Soft Delete User
Method: POST

URL: http://localhost:3000/api/softdelete

Recover Soft Deleted User
Method: POST

URL: http://localhost:3000/api/recoversoftdelete

Update Password
Method: POST

URL: http://localhost:3000/api/updatePassword

Body (JSON):


{
  "oldPassword": "password123",
  "newPassword": "newPassword456"
}
Reset Password
Method: POST

URL: http://localhost:3000/api/resetPassword

Body (JSON):


{
  "newPassword": "newPassword456"
}
